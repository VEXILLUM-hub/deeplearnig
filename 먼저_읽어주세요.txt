학습 완료 딥러닝 탐색 실험 + Streamlit 실행 패키지

실행
1. ZIP 우클릭 → 모두 압축 풀기. 모든 파일을 함께 풀어주세요.
2. START_STREAMLIT_WINDOWS.cmd를 실행.
3. 자동으로 브라우저가 열리면 실험과 카메라를 선택.
   열리지 않으면 http://localhost:8501 접속.
4. 프레임 슬라이더로 실제 영상, 모델 점수, 관심영역 입력/재구성을 확인.
앱을 사용하는 동안 검은 실행 창을 유지하세요. 종료는 Ctrl+C.
첫 실행은 Python 3.11~3.14 및 인터넷 필요. 학습 모델과 실제 JPEG는 이미 포함되어
원본 38GB ZIP, GPU, 사용자 재학습은 필요하지 않습니다.

보는 내용
- 실제 18개 영상/6개 Run에서 추출한 3,042 프레임.
- 카메라별 정상 영상으로 실제 학습한 신경망 3개와 재구성 오차 점수.
- 원본 공기 유입 조작 시점과 PDI702 증상 주석 시점. 센서 실제 측정값 그래프는 아님.
- 정상 평가 결과, 학습 손실, 촬영 공백, 회복 구간, 점수 CSV 저장.

모델
정상 OP028 학습 / OP031 기준 설정 / OP033 정상 평가 / OP022·023·026 사건 평가.
같은 Run의 카메라와 프레임을 다른 분할에 나눠 넣지 않았습니다.
고정 ROI 24x24 회색 입력 → 64 → 16 → 64 → 24x24 재구성:
은닉층 3개의 전결합 오토인코더입니다. CNN·기포 검출기·미래 증상 예측기는 아닙니다.
카메라별 80 epoch 고정 학습, seed 7, 정상 기준 99백분위, 2프레임 연속 기준 초과.
5초 초과 공백/회복에서 지속 상태를 끊고 미래 프레임으로 현재 점수를 만들지 않습니다.
npz 모델 가중치로 앱에서 실제 추론합니다. 저장 점수는 재현 확인에 사용합니다.

이번 결과
정상 평가 OP033 Cam1은 비회복 프레임의 약 99.4%, Cam2는 약 63.3%가 지속 플래그.
Cam0은 OP033 촬영 각도가 달라 정상 비교 평가에서 제외합니다.
사건 3건에서 조작~센서 사이에 새로 시작된 지속 플래그는 0건입니다.
이미 조작 전부터 플래그가 발생한 경우를 선행 탐지 성공으로 세지 않았습니다.
이 설정은 사건에 특이적인 경보나 기포 식별 성능을 입증하지 못했습니다.
정상 학습 Run이 1개뿐이므로 다른 Run/구도/공정 상태 차이에 민감할 수 있습니다.
80 epoch 예산 내 최적화 수렴 경고가 있었으며 최적 모델을 보증하지 않습니다.
기포 라벨과 센서 원본값·시계 동기화 오차가 없어 미래 증상 예측은 학습하지 않았습니다.
기포가 없다고 판정한 것도 아닙니다. 이번 모델의 제한된 탐색 결과입니다.

결과만 공유하려면 23_dl_experiment_report.html부터 확인하세요.
experiment/에 모델, 점수, 분할, 입력 해시, 학습 메타데이터가 있습니다.
재학습은 선택 사항: requirements_training.txt 설치 후 실행된 노트북 사용.
Windows CMD는 정적 확인했고 실제 Windows에서는 실행하지 않았습니다.
Streamlit AppTest로 모든 Run/카메라와 프레임 슬라이더 동작을 검사했습니다.

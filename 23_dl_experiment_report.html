학습 완료: 딥러닝 영상 이상탐지 탐색 실험

정상 영상 기반 카메라별 신경망 3개를 실제 학습하고 3,042프레임의 점수를 계산했습니다. Streamlit 앱에 학습된 가중치와 실제 프레임을 포함했습니다.

이번 결과는 조기 탐지 성공이 아닙니다

평가용 정상 OP033의 Cam1에서 약 99.4%, Cam2에서 약 63.3% 프레임이 지속 플래그였습니다. OP033 Cam0은 구도가 달라 정상 대조 평가에서 제외합니다. 이 높은 정상 플래그 비율은 이번 설정의 일반화와 사건 특이성이 부족함을 보여줍니다.

사건 3건에서 공기 유입 조작~센서 증상 사이 새로 시작된 지속 플래그는 0건입니다. 조작 전부터 발생한 플래그를 선행 탐지 성공으로 세지 않았습니다. 낮은 프레임 오차나 높은 이상 점수는 기포 식별 정확도를 의미하지 않습니다.

분할과 모델

학습 OP028 / 기준 설정 OP031 / 정상 평가 OP033 / 사건 평가 OP022·023·026. 모든 카메라와 프레임은 동일 Run 역할에 묶었습니다. ROI는 이전 탐색에서 정한 것을 재사용했으므로 확증 연구가 아닙니다.

24×24 회색 관심영역을 입력과 재구성 목표로 사용한 전결합 오토인코더(576→64→16→64→576), 은닉층 3개, 카메라별 80 epoch, Adam, seed 7. 정상 학습 Run 1개와 기준 설정 Run 1개뿐입니다. 고정 예산 종료 시 최적화 미수렴 경고가 있어 최적 모델을 보증하지 않습니다.

기준은 OP031 정상 점수 99백분위. 2개의 연속 프레임이 기준을 초과해야 지속 플래그이며, 5초 초과 공백과 회복 구간에서 끊습니다. 미래 프레임으로 현재 판단을 보정하지 않습니다.

Streamlit에서 확인할 내용

실험·카메라를 선택하고 프레임 슬라이더를 움직이면 실제 영상과 관심영역, 모델 입력/재구성, 재구성 오차, 촬영 공백, 공기 유입 조작 시점, PDI702 증상 주석을 함께 볼 수 있습니다. NPZ 가중치로 선택 프레임을 실제 추론합니다. 기록된 조작→센서 반응 간격 34초·1초·9초는 모델이 예측한 지연이 아닙니다.

실행과 공유

ZIP을 모두 풀고 START_STREAMLIT_WINDOWS.cmd를 실행하세요. Python 3.11~3.14와 첫 실행 인터넷이 필요합니다. 원본 Image ZIP·GPU·사용자 재학습은 필요 없습니다. 자동 브라우저가 열리지 않으면 http://localhost:8501에 접속하세요. 실행 창은 유지합니다.

검증과 한계

Streamlit AppTest로 6 Run×3 카메라 및 슬라이더 양 끝을 검사했습니다. 저장 모델 추론 일치, Run 분리, 촬영 공백/회복의 인과적 플래그 초기화도 확인했습니다. Windows CMD는 정적 검토만 했고 실제 Windows에서 실행하지 않았습니다.

기포 시작 정답·실제 센서값·시계 동기화 오차가 없어 기포 식별과 미래 센서 증상 예측은 검증하지 않았습니다. 현재 앱은 기록과 탐색 점수를 확인하는 화면입니다. 모델 미검증 상태를 숨기지 않습니다.
